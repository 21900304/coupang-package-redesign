# 패키지 리디자인 작업 지시서

## 제품 정보
- 제품명: [제품명 입력]
- 카테고리: [예: 식품/음료, 화장품, 생활용품]
- 쿠팡 타겟 고객: [예: 20-40대 여성, 건강 관심층]
- input 이미지: tasks/[제품명]/input.png

## 스타일 방향
- [구체적인 스타일 요청 사항을 자유롭게 입력]
- 예: 기존보다 더 세련되고 프리미엄한 느낌으로 바꿔줘
- 예: 파란색 계열 유지하되 더 고급스럽게
- 예: 한국어 텍스트 레이아웃 개선 필요

## Variation 커스텀 (선택사항)

# 비워두면 기본 5개 스타일 (미니멀 화이트, 프리미엄 다크, 내추럴 크래프트, 모던 플랫, 럭셔리 그라디언트) 사용.

- output 경로: output/[제품명]/
